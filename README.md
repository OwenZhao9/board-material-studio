# 板材宣传素材工坊

板材加工厂专用的本地工具：只需提供拍摄的板材花色照片，批量生成 **朋友圈/小红书九宫格宣传图** 和 **质感运镜宣传视频**。

## 一、启动

双击 `启动.command`（首次可能需要在「系统设置 → 隐私与安全性」允许运行），浏览器会自动打开 `http://localhost:3888`。

也可以用终端启动：

```bash
cd 到本目录
node server.mjs
```

依赖：
- **Node.js ≥ 18**（必需）
- **ffmpeg**（可选，用于「演示模式视频」和「成片合成」，`brew install ffmpeg`）

## 二、使用流程（对应页面五个步骤）

1. **① 花色素材** — 把拍摄的板材照片拖进去，填写「花色编号 + 名称」（如 `L8310 BTRL` / `榆悦`）。可填品牌名、上传 Logo、填小红书号，导出时自动叠加水印。
2. **② 场景与提示词** — 默认 9 个场景（电视墙 / 玄关 / 衣柜 / 茶室 / 餐边柜 / 全屋 / 平铺物料 / 纹理特写 / 中岛），提示词全部可编辑、可一键恢复默认，也能添加自定义场景。视频运镜提示词（推拉、环绕、光影扫纹理）同样可改可恢复。
3. **③ 平台与密钥** — 选择生图 / 生视频平台，粘贴对应 API Key。Key 只保存在你自己电脑的浏览器 localStorage 中，请求由本机 Node 服务转发，不经过任何第三方服务器。接口地址可改成中转站地址。
4. **④ 批量生成图片** — 勾选花色 → 开始。每个花色 × 每个场景一张图，自动按花色分组成九宫格，支持单张重生成、放大预览、带水印下载、整组打包 ZIP。
   - **多花色组合模式**：「每张图使用花色数量」选 2/3/4 种，可做双拼/三色/四色配色方案图——先选中的花色为主花色（大面积柜体墙板），后选的做辅助拼色和点缀，搭配指令在第②步可改。组合模式支持即梦 Seedream（最多14张参考图）、通义千问（最多3张）、Gemini、GPT-Image；可灵仅支持单花色。
5. **⑤ 视频与成片** — 在生成的图上点 🎬 送入视频队列，图生视频（带运镜）；完成的片段可再合成 **带标题卡、花色标注、BGM 的竖屏宣传成片**（对齐验收样片风格）。

先用 **演示模式**（不消耗任何 API 额度）跑一遍全流程，熟悉后再填真实 Key。

## 四、产出文件

所有生成结果都保存在本目录的 `output/` 文件夹（页面右上角可一键打开）：

```
output/
  花色素材/          上传的花色原图
  图片/<花色>/       生成的场景图，按花色分组
  视频/              生成的视频片段
  成片/              合成的宣传成片
```

## 五、常见问题

- **服务状态显示未装 ffmpeg**：`brew install ffmpeg` 后重启服务；不影响生图和调用平台生视频，只影响演示视频和成片合成。
- **某平台报错**：先核对 Key 是否有效、账户是否开通了对应模型的权限/余额；报错信息会原样显示在图片格子/视频任务上。
- **换电脑/清浏览器缓存**：Key 和任务记录存在浏览器里会丢失，但 `output/` 里的成品文件都在磁盘上，不会丢。
