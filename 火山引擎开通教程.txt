========================================================
   火山引擎 API 开通教程
   （生图 Seedream + 生视频 Seedance）
   给完全新手看，照着一步步做即可
========================================================

【要点先说】
· 一共四步：注册实名 → 建密钥 → 开通模型 → 充值
· 生图和生视频是两个不同模型，要分别开通，缺一不可
· 开通不花钱，只有真正出图/出视频时才按次扣费
· 全程在这个网址操作：https://console.volcengine.com/ark


--------------------------------------------------------
第 1 步  注册并实名认证
--------------------------------------------------------
1) 电脑浏览器打开：https://console.volcengine.com/ark
2) 用手机号注册、登录
3) 按提示完成【实名认证】
   · 个人：身份证认证
   · 公司：营业执照认证
   ※ 不实名认证，后面无法调用，必须先做


--------------------------------------------------------
第 2 步  创建 API Key（密钥）
--------------------------------------------------------
1) 登录后，看左边菜单，点【API Key 管理】
2) 点【创建 API Key】按钮
3) 会生成一串以 ark- 开头的密钥，例如：
      ark-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
4) 【立即复制保存好】——它只完整显示这一次！

安全提醒：
· 这串密钥等于你账户的钥匙，别发到群里、别截图外传
· 万一泄露了，回到这个页面把旧的删掉、重新建一个


--------------------------------------------------------
第 3 步  开通模型（最关键，两个都要开）
--------------------------------------------------------
1) 左边菜单点【开通管理】
   （有的界面是在【模型广场】里点进每个模型再开通）

2) 找到下面两类模型，各点一次【开通】：

   ● 生图：豆包 Seedream 系列
       推荐开通：Seedream 5.0 Lite（便宜够用）
       模型编号：doubao-seedream-5-0-lite-260128

   ● 生视频：豆包 Seedance 系列
       推荐开通：Seedance 1.5 Pro
       模型编号：doubao-seedance-1-5-pro-251215

3) 开通是免费的，点一下就行

※ 如果没开通就去用，会报这个错：
     ModelNotOpen ... has not activated the model ...
   看到这个错，就是回来这一步把对应模型开通即可


--------------------------------------------------------
第 4 步  充值
--------------------------------------------------------
1) 左边菜单点【费用中心】或【账户】，点【充值】
2) 大概花费参考：
     · 生图一张：几分钱
     · 生视频一条 5 秒：约 1 元
3) 先充几十块，够用很久

※ 注意：Seedance 2.0 系列要求账户余额超过 200 元才能开通；
   Seedance 1.5 Pro 没有这个限制，新手用 1.5 Pro 即可


--------------------------------------------------------
第 5 步  填进工具里用
--------------------------------------------------------
打开「板材宣传素材工坊」网页，进【第③步 平台与密钥】：

  生图平台   →  选「即梦 Seedream（火山方舟）」
              模型下拉选：Seedream 5.0 Lite
              把第 2 步复制的 ark- 密钥粘进去

  生视频平台 →  选「即梦 Seedance（火山方舟）」
              模型下拉选：Seedance 1.5 Pro
              粘同一把 ark- 密钥（生图生视频共用一把）

接口地址不用改，工具里已经填好了。

※ 模型下拉框里，只选你已经开通的那个型号；
  选了没开通的会报 ModelNotOpen。


--------------------------------------------------------
常见问题
--------------------------------------------------------
Q：报错 ModelNotOpen 怎么办？
A：回第 3 步，把对应的 Seedream / Seedance 模型点【开通】。

Q：报错说余额不足 / 欠费？
A：回第 4 步充值。

Q：密钥忘了 / 泄露了？
A：到【API Key 管理】删掉旧的、重新创建一把，再更新到工具里
   （生图、生视频两处都要更新成新密钥）。

Q：想要更高画质？
A：控制台把更高级的型号（如 Seedream 4.5、Seedance 2.0）也【开通】，
   再回工具第③步的模型下拉框里切换。
